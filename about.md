# About Neon Noir

**Neon Noir** is a cyberpunk-inspired Jekyll theme — deep dark backgrounds, electric magenta/cyan glows, perspective grid, and glitch animations.

## Theme Features

- 🌆 **Perspective grid** — faux-vanishing-point background in pure CSS
- ⚡ **Neon glow effects** — `box-shadow` glow on every interactive element
- 📺 **Scanline overlay** — subtle CRT scanlines across the viewport
- ✂️ **Glitch animation** — clip-path glitch on post titles (load + hover)
- 🏷️ **Tag system** — outlined cyan chips + filterable tag archive
- 📱 **Fully responsive** — mobile-first nav
- ⚡ **Zero dependencies** — vanilla JS only

## Configuration

```yaml
neon:
  accent: "magenta"   # magenta | cyan | amber | green
  grid: true
  scanlines: true
  glitch: true
```
